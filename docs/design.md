# RPG『ポクポク』 - 開発指示書

## 1. プロジェクト概要
*   **ゲームタイトル:** ポクポク
*   **ジャンル:** スーパーファミコン風2DコマンドバトルRPG
*   **ターゲット環境:** Webブラウザで動作（HTML5/Canvas + JavaScript, または Godot EngineのWebエクスポート）
*   **デザインテーマ:** 登場キャラクター、フィールドのオブジェクトに至るまで、無表情で愛らしい「(・.・)」の顔がベース。
*   **開発の進め方:** 小規模なLLMに実装させるため、一度にすべてを作らず、「1. マップ移動とUIのモック」「2. 戦闘システムの基礎」「3. データ読み込みとフラグ管理」のように段階的（イテレーティブ）に実装すること。

## 2. ストーリーと世界観
*   **あらすじ:** 突如現れた魔王によって王女がさらわれた。選ばれた若者（主人公）が世界を巡り、アイテムを駆使して魔王を倒す。
*   **タイトルの謎（重要）:** タイトル『ポクポク』は、本作の最弱モンスターの名前である。一見すると意味不明だが、ゲームを進めるにつれて「なぜこのタイトルなのか」という謎をプレイヤーに感じさせる、少しシュールで意味深な雰囲気を全体に漂わせること。
*   **裏設定（泣ける要素）:** 魔王はかつて王様の親友（または王妃の弟など）だった。過去の悲劇から闇に堕ちており、道中の村人の話やイベントでそのやさしかった過去や悲しい真実が徐々に明かされる。
*   **シナリオ管理:** 後から非エンジニアでもテキストやフラグを修正できるよう、セリフやイベントデータはJSONなどの外部データ構造で管理すること。

## 3. ゲームシステム
*   **プレイヤーステータス:** 主人公1人のみ。最大レベルは20想定。
*   **魔法システム:** 主人公自身は魔法（MP消費）を使えない。代わりに「何度でも使える魔法アイテム（例：ファイアロッド、ヒールスタッフ）」を駆使して戦闘やマップのギミックを解く。
*   **戦闘システム:** 
    *   画面遷移ありのSFC風マルチウインドウ（画面下部にステータス、コマンド、メッセージを分割表示）。
    *   コマンドは「たたかう・どうぐ・にげる」のシンプル構成。
    *   敵には属性や弱点（炎に弱い、硬いので爆弾が効くなど）があり、アイテムの使い分けが攻略の鍵になる。
*   **アセット:**
    *   画像（スプライト、背景）は別途提供する。
    *   BGM/SEはWAV形式で提供する（8bitサウンド）。

## 4. エリアと進行ルート
1.  **エリア1：荒れ果てた平地と城周辺（想定Lv 1〜7）**
    *   雰囲気：魔物に襲われた爪痕が残る物悲しい場所。
    *   目的：はじまりの町で装備を整え、洞窟で「ファイアロッド」を入手する。
2.  **エリア2：平和だが貧しい山（想定Lv 8〜14）**
    *   雰囲気：人々は質素だが穏やか。レアアイテムや鉱石が眠る。
    *   目的：山の主を呪いから解放し、毒沼を渡るための「浄化のアミュレット」を入手する。
3.  **エリア3：豪華な海・湖と魔王城（想定Lv 15〜20）**
    *   雰囲気：きらびやかなリゾート地のような場所だが、奥に魔王城がそびえる。
    *   目的：強力な魔法アイテムを集め、魔王と決戦。

## 5. エネミーデータ（全10種）
1.  **ポクポク:** (・.・)の顔で歩く最弱の敵。タイトルの由来。
2.  **カレクサ:** 荒れ地に生える草。炎アイテムが弱点。
3.  **ドスン（エリア1ボス）:** 巨大。物理防御が極めて高く、炎アイテムでないとダメージが通らない。
4.  **カチコチ:** 岩の敵。通常攻撃を弾くが、特定のアイテムに弱い。
5.  **ヒュン:** 風のようにすばしっこく回避が高い。アイテム攻撃なら必中。
6.  **ユキダマ:** 氷魔法で1ターン休みにしてくる。炎が弱点。
7.  **ヤマヌシ（エリア2ボス）:** 山の主。多彩な魔法を使う。倒すと正気に戻り、悲しい過去を語る。
8.  **チャプ:** 水辺の敵。炎アイテムのダメージを半減する。
9.  **キラリン:** レア敵。すぐ逃げるが、倒すと大量のお金を落とす。
10. **マオウ（最終ボス）:** 王冠を被った(・.・)。強力な全体攻撃とアイテム封じを使用。戦闘前後に重要なストーリーテリングあり。
